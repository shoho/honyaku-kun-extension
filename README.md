# 翻訳くん（Honyaku-kun）🈂️

英⇄日をその場で翻訳・校正する Chrome 拡張機能。ツールバーのアイコンをクリックすると右側にサイドパネルが開き、英文⇄和文の翻訳に加えて、ニュアンス（トーン）の指定、同一言語選択時のネイティブ校正、覚えておくと便利な表現の学習メモまでまとめて表示します。翻訳エンジンには Google Gemini（Flash 系）を使用します。

> nani.now のようなシンプルで気持ちいい翻訳パネルを目指した個人プロジェクトです。

## 特長

- 🪟 **サイドパネル** — アイコンをクリックすると右側にパネルが開く（Chrome Side Panel API）
- 🌐 **言語自動判定** — 入力が日本語か英語かを自動判定し、反対の言語へ翻訳。方向は手動でも切替可
- 🎭 **ニュアンス（トーン）選択** — 💬 チャット / 🤝 同僚 / 🙇 上司 / ✉️ 一般 / 📰 記事 から文体を選べる
- ✨ **校正モード** — 元と先に同じ言語を選ぶと、翻訳ではなく**ネイティブで自然な表現に校正**
- 💡 **学習メモ** — 覚えておくと便利な表現・別の言い回し・解説を日本語の箇条書きで提示
- 🖱️ **右クリック翻訳** — ページ上でテキストを選択 →「翻訳くんで翻訳」で即翻訳
- 🌓 ライト / ダークモード対応、⌨️ `⌘/Ctrl + Enter` で実行

## セットアップ

### 1. Gemini API キーを取得

[Google AI Studio](https://aistudio.google.com/app/apikey) で API キーを発行します（無料枠あり）。

### 2. 拡張機能を読み込む

1. このリポジトリをクローン（または ZIP をダウンロードして展開）
   ```bash
   git clone https://github.com/shoho/honyaku-kun-extension.git
   ```
2. Chrome で `chrome://extensions` を開く
3. 右上の **デベロッパーモード** を ON
4. **パッケージ化されていない拡張機能を読み込む** をクリックし、`honyaku-kun-extension` フォルダを選択

### 3. API キーを設定

1. ツールバーの「訳」アイコンをクリックしてパネルを開く
2. 右上の ⚙️（設定）を開く
3. **Gemini API キー** を貼り付けて **保存**

> 🔒 API キーは `chrome.storage.local`（この端末のブラウザ内）にのみ保存され、翻訳リクエスト以外で外部に送信されることはありません。

## 使い方

- **翻訳**: 原文を入力 →「翻訳する」。元/先言語が `自動` 同士なら、入力言語を判定して反対の言語へ翻訳します。
- **校正**: 元と先に同じ言語（例: `English → English`）を選ぶと「校正する」になり、自然なネイティブ表現に整えます。
- **トーン**: チップでニュアンスを選ぶと、その文体に合わせて出力されます（選択は保存されます）。
- **学習メモ**: 翻訳/校正結果の下に、覚えておくと便利な表現などが箇条書きで表示されます。

## モデルの変更

設定画面の **モデル** 欄でモデル ID を変更できます。

- 既定値: `gemini-3.1-flash-lite`
- 例: `gemini-flash-latest`（常に最新 Flash を指すエイリアス） / `gemini-2.5-flash` など

## ファイル構成

```
manifest.json     拡張機能の定義（Manifest V3）
background.js     Service Worker（パネル起動・右クリックメニュー）
sidepanel.html    サイドパネルの UI
sidepanel.css     スタイル（和テイスト・ライト/ダーク対応）
sidepanel.js      翻訳・校正ロジック（言語判定・Gemini 呼び出し・学習メモ）
icons/            アイコン（16 / 48 / 128px）
```

## 技術メモ

- Manifest V3 / Vanilla JS（ビルド不要・依存ライブラリなし）
- Gemini API の **構造化出力（responseSchema）** で「訳文＋学習メモ」を JSON で取得
- 長文で出力上限（`MAX_TOKENS`）に達した場合は、壊れた出力を表示せず案内を表示
- 書体は Google Fonts（Zen Maru Gothic / Zen Kaku Gothic New）、未取得時は OS の丸ゴシックにフォールバック
